# Lernheft Marketing

Lern-App zu den Zusammenfassungen *Marketing – Grundbegriffe* und *Marketing-Mix*.

**Starten:** `index.html` im Browser öffnen (Doppelklick). Es braucht keinen Server und kein Internet.

**Notizen geändert?** Im Ordner `node build.js` ausführen. Dann werden die beiden `.md`-Dateien
aus dem Second Brain neu und unverändert übernommen.

- `data/content.js`: deine Notizen (automatisch erzeugt)
- `data/tasks.js`: Karteikarten, Quiz, Zuordnen, Reihenfolge, Rechenaufgaben
- `assets/`: Design (`styles.css`), Darstellung (`md.js`), App-Logik (`app.js`)
